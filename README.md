# Сложно сосредоточиться

Учебный проект Яндекс Практикума. Это адаптивная страница о том, почему внимание рассеивается и какие привычки помогают сосредоточиться.

Новые задачи после проекта «Посмотри в окно» — адаптивная сетка для разных экранов и переключение цветовых схем. На странице можно выбрать светлую или тёмную тему, а режим «Авто» учитывает настройки устройства.

## Технологии

- HTML для разметки статьи и галереи.
- CSS Grid, Flexbox и медиазапросы для адаптивной вёрстки, CSS-переменные для цветовых схем.
- JavaScript для переключения темы и сохранения выбора.

## Локальный запуск

Склонируйте репозиторий и откройте `index.html` в современном браузере. Установка зависимостей и сборка не требуются.
